# Sales-Management-System
Web application for managing sales leads, contacts and tasks. 
Tech Stack

Members
Olzhas Koishybek, Zhannur Yeleusizova, Idrissova Yekaterina

Frontend: Angular 17+, TypeScript
Backend: Django 5+, DRF, SQLite
Auth: JWT (Token-based)

How to run
Backend: python manage.py runserver Frontend: ng serve
